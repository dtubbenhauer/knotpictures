# Counting crossings in a published knot table

This experiment uses all fifteen diagrams on Jkasd’s *Knot table* (2008). The table contains a round unknot and one diagram for each of the fourteen prime knot types through seven crossings, up to mirror image. The labels printed on the table supply the expected crossing counts for these particular drawings. After running `python code/fetch_inputs.py paper` from the repository root, `knots.png` is the exact raster from `arXiv/figs/knots.png` in the manuscript archive. It measures 1,280 by 954 pixels and has SHA-256 digest `b900392adda288c6b06df3526bf69c2ca266cbc820dc77c1bc5f97a4c3954184`. Jkasd released the artwork into the public domain. [Original artwork and credit](https://commons.wikimedia.org/wiki/File:Knot_table.svg)

Run `python table_baseline.py` in an environment with Pillow, NumPy, SciPy, and Matplotlib. The experiment used versions 13.0.0, 2.3.5, 1.17.0, and 3.10.8 respectively. The script resolves paths relative to itself.

The experiment composites the table over white and extracts one 230-by-230 square per diagram, excluding the printed label. `manifest.csv` gives the half-open crop coordinates and expected counts and the program builds the images in `crops/`. Each test size is resized directly from the native crop with Pillow Lanczos. The counter thresholds ink intensity with Otsu’s method and counts eight-connected foreground components. For the round circle it interprets one component enclosing exactly one hole as zero crossings. Holes are four-connected background regions disconnected from a padded exterior. No parameters are fitted to knot identity or label. Both raw component counts and the circle correction are recorded.

`observations.csv` records 105 picture–size pairs from fifteen underlying drawings. `summary.csv` groups them by size. `phase-observations.csv` repeats the experiment after translating each crop by zero or one original pixel in each direction. `phase-summary.csv` reports each translation separately. All shifted crops have white borders. Differences at low resolutions illustrate the influence of alignment with the sampling grid. These experiments test one drawing convention and measure visible crossings. A component count cannot identify the knot type or recover its PD code.

`resolution-example.png` uses a distinct color per connected foreground component, reused after ten components. Each row displays one diagram at four resolutions. At low resolution, an underpass gap can vanish and several formerly disjoint ink arcs can join.
