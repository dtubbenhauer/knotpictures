# Figures

The PDF files in this directory are new figures prepared for the revised paper or its experiment companion. The published input photographs, original paper screens and source poster can be recovered with [the input downloader](../code/fetch_inputs.py).

The Culprit is a new drawing of the ten-crossing unknot by Ken Millett. Its combinatorics are transcribed from the grid in Figure 15 of Henrich and Kauffman, *Unknotting Unknots*. The script lays out the faces anew and marks a bigon and a triangle. [Mathematical source](https://doi.org/10.4169/amer.math.monthly.121.05.379)

The appendix figure scripts can each be run with Python. Only the photo panel created by `reading-figures.py` needs the retrieved arXiv images. The experimental figures are also regenerated by [reproduce.py](../code/reproduce.py), with figure PDFs placed alongside the corresponding script or in its results directory.
